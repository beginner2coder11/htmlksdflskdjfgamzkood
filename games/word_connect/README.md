# Word Connect — HTML5 word puzzle template

Swipe letters on the wheel to spell words and fill the crossword. It ships with 150 levels across
10 illustrated chapters plus a 60-puzzle daily rotation. Pure HTML/CSS/JS with no build step
needed to play. It runs offline, on the web or wrapped as an Android APK.

## Run
Serve the folder with any static server (for example `python3 -m http.server`), or drop it into an HTML-to-APK converter.

## Features
- **Swipe wheel:** letters connect with a line and each letter plays a rising note. Back-track by
  swiping to the previous letter.
- **Crossword grid:** found letters fly from the word bubble into their squares.
  Wrong words shake, repeats flash the word already on the board, and long words trigger
  praise ("Excellent!", "Amazing!").
- **Bonus words:** any real word that isn't in the puzzle fills the Bonus Jar, which pays coins when full.
- **Hints:** a lightbulb (reveal a letter) and a target (tap any square to reveal it). A free one is
  offered for a rewarded ad when you're short on coins.
- **Free shuffle** with an animated reseat.
- **10 chapters** with code-drawn landscapes: meadow, lagoon, desert, alpine, forest, twilight city,
  reef, canyon, aurora and starry night. Each has its own accent color, chapter-clear rewards, and
  replay of finished levels.
- **Daily Puzzle** (one per day, bonus reward) and a 7-day **Daily Gift** streak.
- **Progress:** auto-saved, so a level resumes exactly where you left it.
- **Tutorial:** an animated hand on level 1.
- **Audio:** synthesized SFX and a music-box loop (no audio files needed). Haptics on mobile.
- **Ads:** interstitial every N levels and rewarded ads, via an Android WebView bridge or any web SDK.

## Levels: make your own
Levels are generated by a Node script and saved to `js/levels.js`:
```
node tools/build_levels.js                         # 150 levels + 60 daily
node tools/build_levels.js --levels 300 --daily 90 --seed 7
```
- **Answers** come only from `tools/common_words.txt`, so every required word is familiar. Add or
  remove words there, or translate the list for another language.
- **Bonus words** also accept the system dictionary (`/usr/share/dict/words` on macOS/Linux) and simple
  plurals, minus `tools/blocklist.txt`.
- **Difficulty:** 3-letter wheels at the start, then 4, 5, 6 and finally 7-letter wheels with up to 9 words.
- **Validation:** every generated grid is checked so crossings agree and no stray letter runs appear.
- **Openers:** `PINNED` in the script sets the first few levels by hand.

## Reskin
1. `js/config.js`: chapter names, scenes and colors, praise words, coin costs and rewards.
2. `css/style.css`: UI tokens in `:root` (each chapter's accent color is applied automatically).
3. `assets/`: optional art (see `assets/README.md`).

## Ads
All ad calls go through `js/ads.js`:
- **Android (AdMob):** expose `window.GameAdsBridge.showInterstitial()` / `.showRewarded()` and call back
  `window.onAdClosed()` / `window.onRewardedResult(true|false)`.
- **Web portals:** fill in `webSdk` in `ads.js`. Set `ads.simulate: false` in config for release.
